# limzhengjie.github.io

Personal site for **Zheng Jie Lim** — data and research at Artemis.

v1 is a single static homepage (`/`) for GitHub Pages. No build step.

The homepage plays the restored terminal boot intro, then reveals the quiet identity (name, H1, links). `prefers-reduced-motion` skips the animation.

## Custom domain

Canonical, Open Graph, Twitter, schema `Person.url`, `robots.txt`, and `sitemap.xml` use `https://limzhengjie.com/`. A root `CNAME` file lists `limzhengjie.com` for GitHub Pages.

Merge this after Pages custom domain + DNS + Enforce HTTPS are live. GitHub 301s `https://limzhengjie.github.io/` → `https://limzhengjie.com/` when the custom domain is primary.
